**Sanaq AI** — это готовая микросервисная платформа на базе **FastAPI**, **Aiogram 3** и **OpenAI API** для полной автоматизации продаж в интернет-магазинах, цветочных салонах, автозапчастях и сфере услуг через **Telegram, WhatsApp и Instagram Direct**.

Система выполняет роль **автономного 24/7 менеджера по продажам**, умеющего общаться на нескольких языках, распознавать фотографии товаров, транскрибировать голосовые сообщения, оформлять заказы и передавать управление человеку при необходимости.

## 1. Описание проекта и ключевые фишки

### 🤖 1. Умный ИИ-Консультант
* **LLM & Мультимодальность**: Работает на базе OpenAI `gpt-4o-mini`.
* **Vision (Распознавание изображений)**: Клиент может отправить фото товара или скриншот из каталога — ИИ автоматически определит артикул и найдет товар в базе данных.
* **Whisper (Голосовые сообщения)**: Автоматическая расшифровка входящих голосовых заметок клиента через модель `whisper-1` и мгновенный ответ на текст запроса.

### 🌐 2. Мультиязычность из коробки
* **Детекция языка в реальном времени**: ИИ автоматически распознает язык клиента (**Казахский**, **Русский**, **Английский**) и ведет весь диалог исключительно на языке собеседника.
* Поддержка смешанных контекстов и регионального сленга (например, переписка на Казахском языке с латиницей/кириллицей).

### 🛒 3. Автоматический парсинг и оформление заказов
* ИИ вежливо консультирует по ассортименту, ценам и наличию на складе.
* В ходе диалога ИИ извлекает данные: **Имя**, **Телефон**, **Адрес доставки**, **Время**, **Состав заказа** и текст для открытки/пожелания.
* Заказ автоматически заносится в БД со статусом `pending`, а товар зарезервирован с автоматическим уменьшением остатка (`stock`).

### 🤝 4. Human-in-the-Loop (Эскалация на оператора)
* Если клиент проявляет негатив, задает сложные технические вопросы или просит связать с "живым" человеком, ИИ переводит клиента в режим **Human-in-the-Loop**.
* Бот отправляет уведомление администратору в Telegram. ИИ временно приостанавливает ответы данному клиенту до выполнения команды `/resolve`.

### 📊 5. Интерактивный Telegram-бот для владельца (Aiogram 3)
* Управление каталогом товаров и ценами напрямую из Telegram.
* Получение мгновенных уведомлений о новых заказах и эскалациях.
* Утверждение/отклонение ручных переплат по реквизитам (Kaspi/P2P) с автоматическим уведомлением клиента.
* Генерация ежедневных финансовых отчетов продаж (`/report`).

### ⚡ 6. Высшая производительность для дешевых VPS (2GB RAM)
* Взаимодействие с OpenAI через асинхронный легковесный HTTP-клиент `httpx` (без памяти-затратных официальных SDK).
* СУБД SQLite с включенным режимом **WAL (Write-Ahead Logging)** для параллельного чтения и записи.
* Встроенная защита от спама и DDoS (**slowapi** rate-limiter).

## 3. Настройка конфигурации (.env)

Все настройки приложения считываются централизованно через `config.py` из файла `.env`.

### 🛠 Шаг 1. Создание файла переменных окружения
Скопируйте шаблонный файл `.env.example` в `.env`:

```bash
cp .env.example .env
```
*(На Windows PowerShell: `copy .env.example .env`)*

Ниже приведен полный пример готового файла `.env` с описанием каждой опции:


## 4. Быстрый запуск через Docker

Запуск всего комплекса (FastAPI бэкенд + Telegram Admin Bot) выполняется **одной командой**.

### 🚀 Шаг 1. Перейдите в папку проекта
```bash
cd /path/to/Sanaq-AI
```

### 🚀 Шаг 2. Запустите контейнеры
```bash
docker-compose up --build -d
```
*(Или через `docker compose up --build -d` в новых версиях Docker)*

### 🔍 Шаг 3. Проверьте статус запущенных сервисов
```bash
docker-compose ps
```

Вы должны увидеть два работающих контейнера со статусом `Up`:
* **`sanaq_ai_app`**: FastAPI бэкенд (порт `8000`), обрабатывающий вебхуки и REST API.
* **`sanaq_ai_bot`**: Асинхронный Telegram-бот администратора (Aiogram 3).

## 5. Управление базой данных SQLite

База данных хранится в локальном файле `sanaq.db` в корне проекта. При запускe Docker данный файл автоматически монтируется в контейнеры (`./sanaq.db:/app/sanaq.db`), что гарантирует **сохранность всех данных** при перезапуске или пересборке контейнеров.

### 💾 1. Создание бэкапа (Backup)

Для создания мгновенной резервной копии базы данных без остановки сервера выберите удобный способ:

#### Способ A. Горячий бэкап через CLI Docker:
```bash
docker exec sanaq_ai_app sqlite3 /app/sanaq.db ".backup '/app/sanaq_backup_$(date +%Y%m%d_%H%M%S).db'"
```

#### Способ B. Простая копия файла в системе:
```bash
cp sanaq.db sanaq_backup_$(date +%Y%m%d_%H%M%S).db
```

#### Автоматизация бэкапов через cron (ежедневно в 03:00):
Добавьте строчку в `crontab -e`:
```bash
0 3 * * * cp /path/to/Sanaq-AI/sanaq.db /path/to/Sanaq-AI/backups/sanaq_$(date +\%Y\%m\%d).db
```

---

### 🔍 2. Просмотр и редактирование таблиц

Для просмотра содержимого базы данных вы можете использовать:
1. **DBeaver / DB Browser for SQLite**: Скачайте клиент и откройте файл `sanaq.db`.
2. **Консольный клиент sqlite3**:
```bash
sqlite3 sanaq.db
```
Полезные SQL-команды в консоли:
```sql
.tables                                   -- Список всех таблиц
SELECT * FROM products;                   -- Просмотр товаров
SELECT * FROM orders ORDER BY id DESC;    -- Просмотр последних заказов
SELECT * FROM clients WHERE needs_human=1;-- Поиск клиентов в режиме эскалации
.quit                                     -- Выход
```

---

### 🔄 3. Миграции и структура таблиц

При старте приложения `main.py` или `tg_admin_bot.py` автоматическая функция `init_db()` создаёт все отсутствующие таблицы в базе данных:
* `businesses`: Профили компаний (название, телефон, API-ключи, реквизиты оплаты).
* `products`: Каталог товаров (наименование, цена, остаток `stock`, категория, артикул).
* `clients`: Данные клиентов, история покупок, язык, статус эскалации (`needs_human`).
* `orders` / `order_items`: Оформленные заказы, суммы, статусы оплаты и адреса доставки.
* `chat_messages`: Полная история диалогов ИИ и клиентов (с изоляцией по `shop_id`).

## 7. Команды Telegram-бота администратора

Владелец бизнеса и менеджеры управляют системой через Telegram-бота (`tg_admin_bot.py`).

| Команда | Описание | Пример использования |
| :--- | :--- | :--- |
| `/start` | Приветствие и справка по командам | `/start` |
| `/products` | Показать полный список товаров и остатков | `/products` |
| `/add` | Добавить новый товар в каталог | `/add Красные Розы 1500 50` |
| `/update` | Обновить цену товара по его ID | `/update 1 1800` |
| `/stock` | Обновить складской остаток товара по ID | `/stock 1 30` |
| `/orders` | Просмотреть последние 10 заказов | `/orders` |
| `/report` | Сгенерировать отчёт аналитики продаж за дату | `/report` *(сегодня)* или `/report 2026-08-30` |
| `/resolve` | Снять эскалацию с клиента (вернуть ИИ) | `/resolve 42` |

## 8. Архитектура и Эндпоинты API

```
                     ┌──────────────────────────────────────────┐
                     │           Входящий клиент                │
                     │  (Telegram / WhatsApp / Instagram / Web) │
                     └────────────────────┬─────────────────────┘
                                          │
                                          ▼
                     ┌──────────────────────────────────────────┐
                     │          FastAPI Backend (:8000)         │
                     │  • Rate Limiter   • Safety Guard         │
                     │  • Webhook Router • Pydantic Validation  │
                     └────────────┬──────────────────┬──────────┘
                                  │                  │
           ┌──────────────────────┴┐                ┌┴──────────────────────┐
           ▼                       ▼                ▼                       ▼
┌────────────────────┐  ┌──────────────────┐  ┌──────────────────┐  ┌──────────────────┐
│   OpenAI GPT-4o    │  │  OpenAI Vision   │  │  OpenAI Whisper  │  │  SQLite Database │
│   (Диалог & ИИ)    │  │  (Поиск по фото) │  │ (Голос в текст)  │  │ (sanaq.db / WAL) │
└────────────────────┘  └──────────────────┘  └──────────────────┘  └──────────────────┘
                                                                             ▲
                                                                             │
                                                    ┌────────────────────────┴─┐
                                                    │ Telegram Admin Bot (:247)│
                                                    │  • Aiogram 3 Middleware  │
                                                    │  • Аналитика & Отчёты    │
                                                    └──────────────────────────┘
```

### Основные эндпоинты API:
* **`POST /chat`** — Прямой чат с ИИ-менеджером (принимает `message`, `image_url` или `audio_path`).
* **`POST /orders`** — Прямое создание заказа (для CRM-систем).
* **`GET /webhook/whatsapp`** & **`POST /webhook/whatsapp`** — Вебхук для интеграции с WhatsApp.
* **`GET /webhook/instagram`** & **`POST /webhook/instagram`** — Вебхук для интеграции с Meta Instagram Direct.
* **`GET /analytics/{business_id}`** — REST-эндпоинт дневной финансовой аналитики.
* **`POST /analytics/{business_id}/send_report`** — Отправка финансового отчета в Telegram админа.
